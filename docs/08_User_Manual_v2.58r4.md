# HMI 指标使用说明书（v2.58r4 正式版）

适用对象：`H4M5_Identification`，版本 2.58r4（2026-11-06 验收通过的正式使用基线）。
本说明书只讲怎么用、怎么看；规则的完整定义见 `docs/01`、`docs/02`。

---

## 1. 这个指标是做什么的

一句话：**在 H4 判断大方向，在 M5 找符合条件的位置并做标记。**

它只做五件事：发现、确认、跟踪、标记、失效。它**不是入场系统**：

| 指标负责 | 指标不负责 |
|---|---|
| 判断 H4 方向（多头 / 空头 / 过渡 / 区间） | 自动开仓、给出买卖指令 |
| 标出 H4 关注区域（POI）、区间、流动性位置 | 止损、止盈、仓位大小 |
| 在 M5 标出订单块，以及六种确认信号 | 判断这笔交易值不值得做、胜率多少 |
| 显示趋势的强度、质量、当前阶段和原因 | |

面板上的强度、质量、阶段都只是**显示**，不会反过来影响任何标记。

**只做顺势**：H4 是多头时只找做多方向的位置，空头时只找做空方向的位置；过渡和区间时不开始新的跟踪。

## 2. 安装与挂图

### 2.1 安装

1. 在 MT5 里点「文件 → 打开数据文件夹」，进入 `MQL5\Indicators`。
2. 新建一个文件夹（例如 `HMI_v2.58r4`），把正式归档包里
   `v2.58r4_正式基线/EX5/H4M5_Identification.ex5` 复制进去。只放这一个文件就能运行。
3. 在 MT5 导航窗口的「指标」上右键点「刷新」。

也可以把归档里 `Indicators/HMI` 的 26 个源码文件整个复制过去，用 MetaEditor 编译（应为 0 错误 0 警告）。
**已经在用的文件夹不要重新编译**，否则就不是验收过的那个程序文件了。

### 2.2 挂图

- 挂在 **M5** 图表上。
- M5 上的订单块和信号标记，默认只在 M1、M5、M15 周期显示；H4 的区域、区间、流动性线在任何周期都显示。
- 同一品种可以挂多张图（例如一张默认参数、一张 ATR 配置），互不影响。

### 2.3 两套参数配置

| 配置 | 怎么设置 | 日志里的参数摘要 |
|---|---|---|
| 默认 | 所有参数不动 | `461F006E` |
| ATR 配置 | 只把 `InpBreakMarginMode`（对话框里叫 margin mode）改成 `MARGIN_ATR_FRAC`，其余不动 | `A047970C` |

两者的区别只有一处：判断「突破」时留的余量，默认是固定 0.3 点（pip），ATR 配置是 H4 的 ATR(14) 的 5%。
波动大的品种（例如黄金）用 ATR 配置时，余量会随波动自动变大。

## 3. 指标的工作流程

从上到下一步步收窄：

1. **H4 方向**：根据 H4 的摆动高低点和结构突破，判断当前是多头、空头、过渡还是区间。
2. **H4 关注区域（POI）**：顺着方向，找 H4 上「订单块 + 缺口」组成的区域，画成方框。
3. **价格触及 POI**：M5 价格进入某个 POI，开始一段「细化时段」，最长 288 根 M5（一天）。
4. **M5 订单块**：在这段时间里，寻找同方向的 M5 订单块。
5. **武装（ARMED）**：价格回到某个 M5 订单块，这个订单块被「武装」，开始一个识别周期。
6. **六种确认信号**：武装之后，独立检查六种信号，哪个成立就标哪个：
   CISD、MSS、BPR、PA ENGULFING（吞没）、PA REJECTION（拒绝）、PA BREAK-RETEST（突破回踩）。

每一步只用**已经收盘**的 K 线。H4 收盘后，要等下一根 M5 收盘（约 5 分钟后）才处理，所以面板在 H4 收盘后 5 分钟左右更新。

## 4. 右上角：趋势面板

### 4.1 精简模式（默认）三行

```
H4 空头｜正常回撤
强度 弱25/100↓｜质量 良好74/100
原因 回撤偏深，近期逆向运行
```

**第一行：方向和阶段**

| 显示 | 含义 | 颜色 |
|---|---|---|
| H4 多头 | H4 处于上升趋势 | 绿 |
| H4 空头 | H4 处于下降趋势 | 红 |
| H4 过渡·偏多 / 偏空 | 原趋势的保护位被破，新方向还没确认 | 金 |
| H4 区间震荡 | 没有趋势 | 灰 |
| H4 等待数据 | 数据还没同步好（刚开机、刚唤醒时） | — |

「｜」后面是当前阶段，见 4.3。

**第二行：强度和质量**

- **强度**：这段趋势推进得有多用力。分数 0–100：低于 35 是「弱」，35–65 是「中等」，65 以上是「强」。
- 分数后面的箭头，是和 3 根 H4 之前比：涨了 5 分以上 ↑，跌了 5 分以上 ↓，变化不大 →。刚换成新趋势、没法比时写「新趋势」。
- **质量**：这段趋势走得稳不稳。分数 0–100：低于 40 是「较差」，40–70 是「一般」，70 以上是「良好」。
- 质量后面如果有「低样本」，表示用来算分的突破事件只有 3 或 4 次（满的是 5 次），分数参考价值稍低。

强度和质量看的是两件事，可以一个高一个低。例如「强度强、质量样本不足」表示刚起来的一段急行情；
「强度弱、质量良好」表示趋势结构很稳，但最近在回撤。

分数的颜色：强 / 良好 天蓝，中等 / 一般 白，弱 / 较差 紫。特意避开红绿，因为红绿已经用来表示空 / 多。

**不是分数的几种写法**（这些时候不会显示旧分数，也不会显示 0）：

| 显示 | 含义 |
|---|---|
| 暂不评级 | 过渡或区间，没有方向，不评分 |
| 样本不足 | 历史 K 线不够（强度要 15 根 H4，质量要 12 根） |
| 样本不足 n/3 | 质量需要至少 3 次已完成观察的突破，现在只有 n 次 |
| 不可用 | ATR 无效，或趋势段的起点、长度无法确定 |
| 等待数据 | 数据还没同步好 |

注意：强度显示「弱0/100」是真的算出来 0 分（最近价格在逆着趋势走），不是出错。

**第三行：原因**

最多两条，说明为什么是这个阶段、这个分数。趋势中没有特别突出的地方时写「无突出分项」，没有趋势时写「—」。

### 4.2 强度和质量是怎么算的

**强度**（三项加权）：

| 分项 | 权重 | 看什么 |
|---|---|---|
| 净推进 | 45% | 最近 12 根 H4，顺着趋势方向净走了多远（相对 3 倍 ATR） |
| 效率 | 35% | 净走的距离占总路程的比例，来回折腾越多越低 |
| 动量 | 20% | 最近 3 根 H4 顺向走了多远（相对 1 倍 ATR） |

**质量**（三项加权）：

| 分项 | 权重 | 看什么 |
|---|---|---|
| 突破可靠性 | 40% | 当前趋势段里，最近最多 5 次顺向突破，突破后 3 根内有没有守住 |
| 回撤健康度 | 35% | 从趋势段起点算，当前回撤了多少，回撤越浅越高 |
| K 线重叠 | 25% | 最近 12 根 H4 相互重叠的程度，重叠越少越高 |

三项不全时不给总分，只在详细模式里显示已有的分项。

### 4.3 当前阶段

按下面的顺序判断，先满足哪条就是哪条：

| 阶段 | 什么时候出现 |
|---|---|
| 样本不足 / 不可用 | 历史不够，或 ATR 无效 |
| 反转待确认 | H4 处于过渡 |
| 区间震荡 | H4 处于区间 |
| 结构待完善 | 有趋势，但还没有有效的保护位，或趋势段长度无效 |
| 深度回撤 | 回撤超过这段趋势的三分之二 |
| 延续推进 | 这根 H4 刚创出这段趋势的新极值 |
| 高位整理 / 低位整理 | 没创新极值，但收盘离极值很近（0.25 倍 ATR 以内）。多头叫高位整理，空头叫低位整理 |
| 正常回撤 | 以上都不是 |

### 4.4 原因的含义

先列「状态」类，再列「风险」类；两类都没有时，才列「强项」。

| 类别 | 显示 | 含义 |
|---|---|---|
| 状态 | 多头保护低点已破 / 空头保护高点已破 | 进入过渡的原因：保护位被收盘突破 |
| 状态 | 多头低点已破（无保护点）/ 空头高点已破（无保护点） | 进入过渡的原因：当时没有保护位，最近的摆动点被破 |
| 状态 | 过渡超 18 根未确认 | 过渡太久没结果，转为区间 |
| 状态 | 缺少保护点 | 趋势中暂时没有有效保护位 |
| 状态 | 波段长度无效 | 趋势段的长度算不出来 |
| 风险 | 回撤偏深 | 回撤超过三分之二 |
| 风险 | 近期突破失败 | 最近的突破里有没守住的 |
| 风险 | 近期逆向运行 | 最近 3 根 H4 在逆着趋势走 |
| 风险 | 价格往返明显 | 效率低于 35，来回折腾多 |
| 强项 | 同向推进明显 / 推进效率高 / 近期推进有力 | 强度的三个分项达到「强」的水平 |
| 强项 | 回撤较浅 / 突破全部守住 / K 线重叠少 | 质量的三个分项达到「良好」的水平 |

### 4.5 详细模式（FULL）五行

把 `InpPanelMode` 改成 `PANEL_FULL`，右上变成带标签的五行：

```
H4 趋势    ▼ 空头
趋势强度   弱 · 11/100 ↓
趋势质量   一般 · 48/100（低样本 3 次突破）
当前阶段   正常回撤
主要原因   近期突破失败，近期逆向运行
```

内容和精简模式相同，只是写得更完整：质量会写明事件次数；样本不足时会列出已有的分项。

## 5. 左上角：诊断面板

### 5.1 精简模式（默认）两行

**第一行：M5 跟踪状态**，五种之一：

| 显示 | 含义 |
|---|---|
| M5 等待数据 | 数据还没同步好 |
| M5 跟踪中（10.28 18:30 起）已确认 3 项 · 待确认 2 项 | 有一个已武装的订单块正在被跟踪。括号里是武装时间（服务器时间）。六种信号里已出现 3 种，还有 2 种可能出现（其余的是这个周期里不会出现的） |
| M5 未跟踪 · H4 POI 已触及（10.28 12:40），等待 M5 区块 | 价格已进入 H4 关注区域，正在等 M5 订单块 |
| M5 未跟踪 · 等待价格触及 H4 POI | 有趋势，但价格还没到关注区域 |
| M5 未跟踪 · H4 非趋势，暂停新跟踪 | 过渡或区间，不开始新的跟踪 |

「跟踪中」后面可能附带两个提醒：

- **锚点失效**：被武装的那个订单块已经被价格打穿。周期没有因此结束，但可靠性下降。
- **H4 趋势已变**：武装之后，H4 的方向状态变过。

「跟踪中」的周期可能是几天前开始的（看括号里的日期）。只要它还有没出现的信号，程序就一直检查它，直到下一个订单块被武装。
带着这两个提醒的旧周期，请谨慎看待。

**第二行：今日波幅**

```
今日波幅占 ADR 47% · 剩余 45.2 pip
```

ADR 是最近 20 个已收盘交易日的平均日波幅。这一行告诉你今天已经走了平均波幅的百分之多少、理论上还剩多少。
达到 80% 变橙色，达到 100% 变红色并加「（已用尽）」。

**临时多出的行**：

- 「流动性历史等待中，流动性线暂定」：MT5 还在下载较早的历史，流动性线暂时可能不全，等一会儿自动消失。
- ATR 行：把 `InpShowATR` 打开后显示 H4 和 M5 的 ATR(14)。

### 5.2 详细模式（FULL）

依次显示：版本行、M5 跟踪状态、H4 结构诊断（突破计数、结构是否干净）、强度分项、质量分项、
H4 POI 数量和被拒绝数量、细化时段、流动性历史状态、周期行（周期号、方向、六种信号各自的状态）、ATR、ADR。

周期行的写法：`CYCLE #2861 BEAR  BPR OK  PA ENGULFING OK  CISD N/A  [ANCHOR INVALIDATED]`

- `OK`：这种信号已经出现。
- `N/A`：这个周期里这种信号不可能出现（例如没有找到可用的参考位）。
- 没列出的：还在等待。
- `LAST CYCLE`：这个周期已经没有可等的信号了，只是留作记录。
- 周期号只是内部编号，重新加载图表后会变，不用在意。

| 标记 | 样子（默认） | 含义 |
|---|---|---|
| H4 POI | 方框：多头青色、空头暗红，实线；带「H4 POI」文字 | H4 的关注区域，还没被触及 |

| 失效 / 过期的 POI | 灰色点线 | 被打穿，或超过 120 根 H4 没用上 |
| H4 RANGE HIGH / LOW | 银色点线方框 | 当前 H4 交易区间的上下沿 |
| 流动性线（BSL / SSL） | 灰色点线 | 区间内的买方 / 卖方流动性位置（摆动高点 / 低点） |
| PDH / PDL | 钢蓝色虚线 | 前一日高点 / 低点 |
| PWH / PWL | 紫色虚线 | 前一周高点 / 低点 |
| PMH / PML | 金棕色虚线 | 前一月高点 / 低点 |
| xxx SWEEP | 橙色文字 | 这条线被刺破后又收了回来（扫流动性） |
| xxx BROKEN | 灰色文字 | 这条线被真正突破 |

### 6.2 时段高低点（Kill Zone）

每个时段画出它的最高、最低价，并向右延伸一段：

| 时段 | 默认时间（**服务器时间**） | 颜色 |
|---|---|---|
| ASIA | 02:00–08:00 | 卡其色 |
| LONDON | 09:00–12:00 | 天蓝 |
| NY AM | 14:30–17:00 | 浅橙红 |
| NY PM | 18:00–20:00（默认关闭） | 淡紫 |

时间是经纪商服务器时间，不是你电脑的时间。时段的名字、起止时间、颜色都可以改。

### 6.3 M5 层（默认只在 M1 / M5 / M15 显示）

| 标记 | 样子（默认） | 含义 |
|---|---|---|
| M5 订单块 | 方框：多头蓝色、空头橙红，实线 | 细化时段里找到的 M5 订单块 |
| 已触及未武装 | 银色点划线 | 被触及，但没有被选为武装对象 |
| 已武装 | **金色粗线**，带「M5 OB ARMED」文字 | 识别周期从这里开始 |
| 失效 / 过期 | 灰色点线 | 被打穿或过期 |
| CISD Level | 白色虚线，带文字 | CISD 的参考价位 |
| MSS Break Level | 白色点划线，带文字 | MSS 的参考价位 |
| BPR 区域 | 紫色方框 | 多空两个缺口重叠的区域 |
| ▲ / ▼ + 信号名 | 文字标签 | 某种信号在这根 K 线收盘时确认。▲ 多、▼ 空 |
| PENDING TOUCH | 金色小字 | 当前未收盘的 K 线正在触及订单块，仅是预览，收盘后才算数 |

六种信号的大致含义：

| 信号 | 含义 |
|---|---|
| CISD | 订单流方向转变：收盘越过武装前那段反向 K 线的起点 |
| MSS | 市场结构转变：收盘越过武装前最近的反向摆动点 |
| BPR | 平衡价格区间：一多一空两个缺口重叠，价格回到重叠区 |
| PA ENGULFING | 吞没形态 |
| PA REJECTION | 长影线拒绝形态 |
| PA BREAK-RETEST | 突破一个近期高 / 低点后回踩不破 |

六种信号各自独立判断，互不依赖；同一个周期里每种最多出现一次。

## 7. 常用设置

在图表上右键 →「指标列表」→ 选中 `H4M5_Identification` →「属性」→「输入参数」。
改任何参数，这张图都会重新计算一次，属于正常现象。

### 7.1 面板

| 参数 | 作用 | 默认 |
|---|---|---|
| `InpPanelMode` | 面板模式：关闭 / 精简 / 详细 | 精简 |
| `InpTrendCorner`、`InpTrendX`、`InpTrendY` | 趋势面板放在哪个角、离角多远 | 右上 |
| `InpPanelCorner`、`InpPanelX`、`InpPanelY` | 诊断面板放在哪个角、离角多远 | 左上 |
| `InpTrendFontSize` / `InpPanelFontSize` | 两个面板的字号 | 9 / 8 |
| `InpPanelFontName` | 面板字体（要能显示中文） | Microsoft YaHei |
| `InpTrendTierColors` 及三个等级色 | 强度、质量是否按等级着色，以及颜色 | 开 |
| `InpPanelBgColor`、`InpPanelBorderColor` | 面板背景色、边框色 | 跟随图表背景 |
| `InpShowADR`、`InpShowATR` | 是否显示 ADR 行、ATR 行 | 开 / 关 |

### 7.2 显示开关

| 参数 | 控制什么 |
|---|---|
| `InpShowH4POI`、`InpShowDeadH4POI` | H4 关注区域；已失效的是否还显示 |
| `InpShowTradingRange` | H4 交易区间 |
| `InpShowLiquidity`、`InpLiqMaxLines` | 流动性线，以及每侧最多画几条 |
| `InpShowPD`、`InpShowPW`、`InpShowPM` | 前日、前周、前月高低点 |
| `InpShowLiqEvents`、`InpLiqSweepDays` | SWEEP / BROKEN 文字，保留几天 |
| `InpShowKillZones`、`InpKZDays` | 时段高低点，画几天 |
| `InpShowM5Blocks`、`InpShowArmedLabel` | M5 订单块、武装文字 |
| `InpShowCISD`、`InpShowMSS`、`InpShowBPR`、`InpShowPA` | 各种信号的标签 |
| `InpShowLevelLines` | CISD / MSS 参考价位线 |
| `InpM5Layer` | M5 层在哪些周期显示 |

每种标记的颜色、线型、线宽、字号都在后面各个「Style」分组里。
线宽大于 1 时，MT5 会把虚线、点线画成实线。

关掉显示只是不画，计算照常进行。

有些参数在对话框里显示的名字不直观（MT5 把源码注释当名字用）。例如 H4 区间线的颜色显示为
「was clrSlateGray: too dark to find」。这只是名字问题，功能正常。

### 7.3 提醒

默认全部关闭。打开 `InpAlertsEnabled` 后，可以在订单块武装、各种信号确认时弹窗（`InpAlertPopup`）
或推送到手机（`InpAlertPush`，需要先在 MT5 里设置好推送）。每种提醒可以单独开关。

### 7.4 日志

`InpLogSignals` 打开后，指标会把每一步的结果写进「专家」日志，文件在 `MQL5\Logs`。
这是验收核对用的，日常使用**可以关掉**。十张图开着时，一天的日志能有一两百 MB。

### 7.5 不建议改的参数

「General」到「Liquidity sweep」这几组是规则参数：历史窗口、突破余量、摆动点左右根数、POI 有效期、
细化时段长度、各种形态的比例等。改了它们，标记结果就会不同，日志里的参数摘要也会变，
不再是验收过的那两套配置。除非清楚后果，否则保持默认。

## 8. 日常使用会遇到的情况

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 刚打开 MT5 或电脑从睡眠唤醒，面板显示「等待数据」 | 行情数据还在同步 | 等几秒到十几秒，自动恢复 |
| 左上多出「流动性历史等待中」 | 较早的历史还在下载，黄金比较常见 | 等一会儿自动消失 |
| 图表突然闪一下、标记重画 | MT5 更新了这个品种的历史数据，指标自动重算，不到 1 秒 | 不用管 |
| 切换周期、改参数、刷新图表后，周期号变了 | 编号按每次计算重新排 | 正常，内容不变 |
| 很早以前的标记，重新加载后不见了或不一样 | 指标只算最近 5000 根 M5（约 17 个交易日）和 500 根 H4，窗口开头那一段算不完整 | 只看近期的标记 |
| H4 收盘了，面板没马上变 | 要等下一根 M5 收盘才处理 | 等约 5 分钟 |
| 夏令时切换后，时段高低点的位置不对 | 时段按服务器时间算，经纪商的服务器时间变了 | 按需要调整 Kill Zone 的起止时间 |
| 某张图的指标不见了 | 指标所在的文件夹被删或改名 | 从正确的文件夹重新挂上 |
| M15 以上周期看不到 M5 订单块和信号 | 默认只在 M1 / M5 / M15 显示 | 改 `InpM5Layer` |

**实时和历史一致**：指标只用收盘后的 K 线。实时出现的标记，之后重新加载图表，会出现在同一位置，
不会事后消失或挪动（窗口开头那一段除外）。未收盘 K 线上的「PENDING TOUCH」只是预览。

## 9. 已知限制

1. **数据窗口移动**：窗口最前面约一天的标记，随着窗口往前推可能变化或消失。
2. **编号会变**：周期号、区域号重新加载后重排。
3. **原因文字的一个小问题**：有趋势但 ATR 无效或历史不足时，第三行写的是「无突出分项」，本应写「—」。
   这种情况很少见，不影响分数、阶段和标记，留到以后的版本修。
4. **有几种阶段出现得少**：高位 / 低位整理、区间震荡在五日实盘验收期间没有在 H4 收盘时出现过，
   它们只做过离线测试。
5. **验收环境**：验收是在一台电脑上白天运行、晚上睡眠的方式下完成的，不是 24 小时不间断运行的测试。
